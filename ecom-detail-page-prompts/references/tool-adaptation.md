# 生图工具适配指引（详情页向）

> 2026-10 快照。生图工具迭代快（约三到四个月一代），本文件提供投喂写法参考；能力与参数以工具官方文档和实际效果为准。

## 二、按工具的写法变体

默认输出"通用版"（分层写法，见下）。用户指定工具时按对应变体调整：

- **Seedream（即梦）**：把结构化清单改写成连贯自然语言句子，保留短词审美描述，删掉堆叠形容词。
- **GPT-Image**：按分层结构组织——任务、主体、结构约束、光线与材质、输出边界，逐层成段。
- **Gemini**：对话式写法——先给参考图与整体要求，图内文字用引号包裹，随后可给多轮修图步骤。
- **Qwen-Image 2.1 Pro**：完整页面提示词可直接投喂。逐页生成时每页单独调用，参考图按「产品主图在前、细节图在后」排序；脚本默认不改写提示词，避免模型重写破坏版式与文字锁定描述。
- **FLUX 等本地模型**：可附种子与负面提示词列表，便于批量复现。

通用版写法（未指定工具时）：先给产品与页面主题，再给构图与版式结构，然后背景、光影、装饰系统，最后主副标题与信息模块文字、输出边界收尾；一页提示词内保持同一套层级顺序。

## 三、中文文字渲染技巧（详情页重点）

详情页信息模块多、文字层级密，是中文渲染出错的重灾区，按以下约束写：

1. 图内文字一律用引号包裹（写"质感如初"而不是 质感如初），需要字体气质时写明（如"圆润黑体"）。
2. 少而准：主标题不超过 10 字、副标题不超过 20 字、卖点标签每条 4 到 8 字；字体层级不超过 3 级。
3. 单页文字总量克制，大段文案、密集参数表会明显拉低渲染准确率；参数名与数值用短词加占位符（如"尺寸：待补充"）。
4. 字号占画面宽度 10% 以上更稳；小字注释与表格线生成后必须人工校对。
5. 文字与背景保持对比，避免叠在复杂纹理、金属反光或产品 Logo 上。
6. 长参数表、规格表优先生成后手动补字或二次编辑，不要依赖一次生成。

## 四、多轮编辑脚本（对话式修图模板）

用户工具支持对话式多轮修图（Gemini、可灵等）时，生成首图后按步骤下达指令，每步只改一个变量：

```
第 1 步（首图）：用完整页面提示词生成基础图。
第 2 步（改文字）：保留画面全部元素，只把主标题改为"【】"。
第 3 步（改图文关系）：保留产品与风格不变，把信息区从【左栏】移到【右栏】。
第 4 步（调细节）：保留整体版式，放大【细节区】并把辅助说明改为"【】"。
```

规则：每步重申保留清单；一次只改一个变量；效果变差时回退上一步重新下达指令，不要叠加新指令硬改。

## 五、AI 标注要点（跨境与内容平台）

页面含 AI 生成模特、试穿人、数字人等逼真人物时，核对标注义务：

- **Amazon**：商品图与 A+ 内容须把 `contains-synthetic-performer` 写入图片 XMP 元数据 `dc:subject`（写入文件名或画面水印无效）。
- **TikTok Shop**：AI 生成内容须披露（画面标注或发布开关）。
- **中国法规**：AI 生成合成内容须显式与隐式双标识。
- 纯产品详情页（无 AI 人物）不涉及人物标注，但商品外观仍须与参考图一致，严禁货不对板。

## 六、本仓库命令行出图通道（Qwen-Image 2.1 Pro）

仓库内 `tools/qwen_image.py` 提供文生图与图生图命令行通道，走阿里云百炼 DashScope 同步接口，模型 `qwen-image-2.1-pro`。密钥只从环境变量 `DASHSCOPE_API_KEY` 或 `--key-file` 读取，不写入任何文件。

```bash
export DASHSCOPE_API_KEY="sk-..."   # 也可用 --key-file 指向密钥文件
python tools/qwen_image.py -p "提示词" -o out
python tools/qwen_image.py -f page03.txt -i product_front.jpg -i product_detail.jpg --size 1024*1536
```

参数要点：`--size` 用 `宽*高`（也接受 `宽x高`）或 `auto`；`-n` 支持 1 到 6 张；`--seed` 固定随机种子；`-i` 可重复，最多 10 张参考图。提示词默认按原文投喂、不做模型改写，需要模型按简单描述扩写时加 `--prompt-extend`。输出默认落在 `out/`，该目录不进版本库。详情页逐页生成时，一页一个提示词文件，参考图顺序固定为产品主图在前、细节图在后。提示词含大量引号或换行时用 `-f` 传文件，避免命令行转义问题。

脚本只存在于仓库与镜像工作区，单独安装技能目录时不带 `tools/`。
