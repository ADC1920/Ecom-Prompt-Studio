# 生图工具适配指引

> 2026-10 快照。生图工具迭代快（约三到四个月一代），本文件提供投喂写法参考；能力与参数以工具官方文档和实际效果为准。

多项为社区实测结论，工具版本迭代快，以官方为准。

## 二、按工具的写法变体

默认输出"通用版"（分层写法，见下）。用户指定工具时按对应变体调整：

- **Seedream（即梦）**：把结构化清单改写成连贯自然语言句子，保留短词审美描述（如"暖调柔光""哑光纸质"），删掉堆叠形容词。
- **GPT-Image**：按分层结构组织——任务、主体、结构约束、光线与材质、输出边界，逐层成段。
- **Gemini**：对话式写法——先给参考图与整体要求，图上要出现的文字用引号包裹，随后给多轮修图步骤（如需）。
- **Qwen-Image 2.1 Pro**：完整 SOP 原文可直接投喂。图生图时参考图按「产品主图在前、细节图在后」排序，并在提示词里说明每张图的职责；脚本默认不改写提示词，避免模型重写稀释 SOP 里的产品锁定条款。
- **FLUX 等本地模型**：可附种子与负面提示词列表，便于批量复现。

通用版写法（未指定工具时）：主体描述在前（任务、产品、场景、构图），材质与光线居中，文字与边界收尾；一份提示词内保持同一套层级顺序。

## 三、中文文字渲染技巧

1. 图内文字用引号包裹（写"电商大促"而不是 电商大促），需要字体气质时写明（如"圆润黑体"）。
2. 少而准：主标题不超过 10 字、副标题不超过 20 字、字体层级不超过 3 级；大段文字会明显拉低渲染准确率。
3. 字号占画面宽度 10% 以上更稳；小字、密集参数表生成后必须人工校对。
4. 文字与背景保持对比，避免叠在复杂纹理、金属反光或产品 Logo 上。
5. 参数表、规格表这类长文排版优先在生成后手动补字或二次编辑，不要依赖一次生成。

## 四、多轮编辑脚本（对话式修图模板）

用户工具支持对话式多轮修图（Gemini、可灵等）时，除完整提示词外可附多轮编辑建议，每步只改一个变量：

```
第 1 步（首图）：用完整提示词生成基础图。
第 2 步（改背景）：保留产品与构图不变，只把背景换为【】。
第 3 步（改文字）：保留画面全部元素，只把主标题改为"【】"。
第 4 步（调光影）：保留产品不动，把光位改为【】，产品画面占比微调至【】。
```

规则：每步重申保留清单；一次只改一个变量；效果变差时回退上一步重新下达指令，不要叠加新指令硬改。

## 五、本仓库命令行出图通道（Qwen-Image 2.1 Pro）

> **调用前必须取得用户授权**：本项目限制任何图片生成模型在调用前都要先说明用途与预计花费并取得同意，Qwen-Image 全系同样适用。规则见仓库 `tools/IMAGE-GEN-AUTHORIZATION.md`。脚本缺 `--authorize` / `--purpose` / `--unit-price` 会直接拒绝，不发出请求。

仓库内 `tools/qwen_image.py` 提供文生图与图生图命令行通道，走阿里云百炼 DashScope 同步接口，模型 `qwen-image-2.1-pro`。密钥只从环境变量 `DASHSCOPE_API_KEY` 或 `--key-file` 读取，不写入任何文件。

```bash
export DASHSCOPE_API_KEY="sk-..."   # 也可用 --key-file 指向密钥文件
python tools/qwen_image.py -p "提示词" -o out \
  --authorize "用户 2026-10-29 14:20 回复：可以" --purpose "产品A 天猫主图第 2 张" --unit-price 0.25
python tools/qwen_image.py -f prompt.txt -i product_front.jpg -i product_detail.jpg --size 1024*1024 \
  --authorize "..." --purpose "..." --unit-price 0.25
```

参数要点：`--size` 用 `宽*高`（也接受 `宽x高`）或 `auto`；`-n` 支持 1 到 6 张；`--seed` 固定随机种子；`-i` 可重复，最多 10 张参考图。提示词默认按原文投喂、不做模型改写，需要模型按简单描述扩写时加 `--prompt-extend`。输出默认落在 `out/`，该目录不进版本库。提示词含大量引号或换行时用 `-f` 传文件，避免命令行转义问题。

授权三项：`--authorize` 填用户原话或带日期的授权说明，不得自行编造；`--purpose` 具体到产品、平台、页面位置；`--unit-price` 填官方页面当时的每张单价，拿不到就先问用户。脚本会打印「张数 × 单价 = 预计花费」并写入 `out/authorization.log`，只留本机。

脚本只存在于仓库与镜像工作区，单独安装技能目录时不带 `tools/`。
