# 正样本语料库

验证过「出得了好图」的提示词存这里，一行一条（`entries.jsonl`）。

## 为什么需要它

SOP 原文教的是方法，方法教不会手感。真正让提示词变好的，是见过同类任务里已经成立的那份成品——
它的颗粒度、它的约束写法、它在哪个地方留了占位符。语料库就是把这批成品留下来，下次同类任务先检索。

它也是**去掉原文库之后仍能工作的那部分**：原文可以删，验证过的样本删不掉。

## 怎么加

```bash
python tools/corpus.py add \
  --title "保温杯 Amazon 白底首图" \
  --prompt-file prompt.txt \
  --platform amazon --category 百货杯壶 --scenario 首图 \
  --score 8 --tags 白底,首图
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 一句话说清这条样本是什么任务 |
| `prompt` | 是 | 完整提示词，不是摘要 |
| `platform` / `category` / `scenario` | 建议 | 检索时会按这三项加权；取值与 `_index.json`、`_rules/` 保持一致 |
| `score` | 建议 | 人工评分 1-10，同分排序时高者靠前 |
| `tags` | 建议 | 逗号分隔，用于检索加权 |

## 怎么用

```bash
python tools/corpus.py search --query "保温杯 白底" -n 3   # 看看有没有同类样本
python tools/corpus.py fewshot --query "保温杯 白底" -n 2  # 直接编译成可贴进提示词的范例段
```

`fewshot` 的输出是给人或模型看的范例段，前面有一句「只学结构与颗粒度，不要照抄产品与卖点」——
照抄产品信息是这条链路最容易出的错，防的是它。

## 维护约定

- 只收**真实出过图且机检或人工验收过**的提示词，构想中的不收。
- 同一平台、品类、场景最多留 2-3 条，多了挤占上下文且检索会互相稀释。
- 评分低于 5 的定期清掉，或者用改写后的版本替换。
- 平台或品类规则变了，先查语料里有没有过期样本，过期就删。
