# 提示词五槽位规范

> 34 篇 SOP 给的是「内容与判据」，本文件给的是「骨架与顺序」。两者是编译器与源码的关系：SOP 决定说什么，槽位决定按什么顺序说、缺什么要拦下来。

## 为什么要有槽位

同一份 SOP，不同人写出来的提示词质量差异很大，通常不是信息不够，而是**顺序和完整度不稳定**：有人先写背景再写产品，有人漏掉输出边界，有人把卖点堆在开头。槽位把顺序固定下来，把「必须写到什么」变成可校验的最低要求。

槽位只管骨架，不替代原文。硬规则（产品锁定、信息真实性、不露脸、平台合规）仍以被读的那篇 SOP 与导演技能为准。

## 五个槽位

| 槽位 | 写什么 | 判定「写够了」的标准 |
|---|---|---|
| `scene` 场景 | 背景材质、空间关系、景深、道具白名单、整体氛围 | 闭眼能想出空间：在哪、多大、什么材质、光从哪来 |
| `subject` 主体 | 产品品类、轮廓比例、颜色材质、包装与标签、朝向与占位 | 不看参考图也能对上产品，且没说成别的品类 |
| `details` 细节 | 卖点、可见文字、标签内容、材质特写、结构件、限定语 | 每条都能追溯到图片可见或用户提供（对应证据账本） |
| `usecase` 用途 | 目标平台、页面位置、比例、受众、商用场景 | 平台与比例明确，且与 `scene` 不冲突 |
| `constraints` 约束 | 保留清单、禁止项、输出边界、合规要求 | 至少 3 条、至多 8 条，且都对本图有意义 |

组装顺序固定为：**保真段 → scene → subject → details → usecase → constraints**。

保真段（产品锁定 + 风格锁）永远在最前。模型对开头的约束服从度最高，把「不许改什么」放在最后一句话里，等于让它最后才看到。

## 与 34 篇的对应

`references/_index.json` 每篇带 `slots` 字段，标出该篇主要产出哪几个槽位：

- 主图台生成类：`scene` + `subject` + `details` + `constraints`
- 详情页台：五槽全用，`details` 与 `usecase` 承担信息密度
- SKU 台：`subject` + `details` + `constraints`（变体差异放 details）
- 模特与视频台：`scene` + `subject` + `usecase`（人物与镜头节奏放 scene）
- 反推台：`subject` + `details` + `constraints`（拆解表另外成文，不进提示词）

## 组装与校验

用 `tools/compose_prompt.py` 组装，避免手写顺序漂移：

```bash
python tools/compose_prompt.py --template > slots.json   # 生成空白模板
python tools/compose_prompt.py slots.json                 # 组装成提示词
python tools/compose_prompt.py slots.json --check         # 组装并跑反 AI 感与必填校验
```

校验口径：

- `subject` 与 `constraints` 必填，缺一即拒绝组装。
- `scene` / `details` / `usecase` 缺失时给警告，不阻断——有些图确实只需主体与边界。
- 组装后自动跑 `slop_check`，error 级问题必须改完才能交付。
- 平台给了就自动补该平台的比例与白底约束（取自 `platform-rules.md` 的机检映射）。

## 一个成品长什么样

```text
以全部参考图为准，参考图之间不一致时以最清晰角度为准。保留清单：哑光不锈钢保温杯，直筒杯身，杯盖三圈旋纹，丝印 logo 位于杯身下部居中。风格锁：暖白 #F6F2EA 背景，左上 45 度柔光 5500K，斜纹亚麻台面。

场景：无缝暖白背景，纵深 1.2 米处有极浅渐变，台面为细斜纹亚麻材质，产品右侧 15 厘米处放一枚同色系杯垫作为唯一道具。

主体：产品正面偏右 15 度，占画面宽约 62%，完整入画不裁切，杯口水平，投影向左下延伸。

细节：杯身哑光拉丝可见细密横向纹理；杯盖与杯身接缝清晰；丝印 logo 保持原样不重绘。

用途：Amazon 主图第二张，1:1，面向 25-35 岁通勤人群，竖版留白用于后续信息层。

约束：保留产品形状、比例、颜色、logo 位置与材质；不要出现文字、水印、多余手指、重复产品或无关道具。
```

注意这份成品里没有「8k」「hyperrealistic」「完美质感」这类词——形体、光位、材质、比例已经把事情说完了。
