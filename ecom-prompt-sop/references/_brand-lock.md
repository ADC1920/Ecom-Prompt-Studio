# 品牌锁：让一套图看起来像同一家的

> 模板只是起点，一致性才是成品感。这里锁的是「跨图不漂移」的那几个变量，不是风格灵感。

## 为什么需要它

单张图好看不难，一套从主图到包装、从首图到详情页的图放在一起像同一个品牌，才是难点。
模型每次生成都会重新解读形容词，「干净高级」在十次生成里能得到十种不同的干净高级。
锁定的办法是把可枚举的视觉变量写死，让变化的只剩画面内容。

## 十个必锁字段

| 字段 | 锁什么 | 取值示例 | 不锁的后果 |
|---|---|---|---|
| `light_direction` | 主光方位角与高度 | 左上 45 度、略高于视线 | 每张光线方向不同，套图看不出是同一组 |
| `light_temp` | 色温 | 5500K 冷白 / 4800K 暖白 | 冷暖混杂，像拼凑的素材 |
| `shadow_type` | 投影性质 | 自然接触影、无投射影 | 有的悬浮有的落地，空间关系矛盾 |
| `bg_color` | 背景色值（不是形容词） | #FFFFFF / #EDE8E1 | 十种白，拼图时露馅 |
| `bg_material` | 背景材质 | 无缝纸、哑光布、木纹 | 质感跳变 |
| `camera_height` | 机位高度 | 平视、略俯 15 度 | 产品比例在各图之间不一致 |
| `lens` | 镜头焦距观感 | 50mm 标准、85mm 压缩 | 透视畸变程度不同，同一产品看着变形 |
| `color_grading` | 调色倾向 | 中性、低饱和暖调 | 一张冷一张暖 |
| `typography` | 字体与排版规则 | 无衬线粗体、标题字高 7% | 详情页每页字体不一样 |
| `negative` | 输出边界 | 无文字、无水印、无多余手指 | 各图违规项不一致 |

## 怎么写进提示词

锁定的字段要**逐字相同**地出现在每张提示词里，不是换个说法描述同一件事。
建议抽成一个 prepend 段，直接复制到每条提示词开头：

```
【品牌锁】主光左上 45 度略高于视线，5500K 冷白，自然接触影；背景纯白 #FFFFFF 无缝纸；
机位平视，50mm 观感；中性调色不加暖调滤镜；无文字、无水印、无边框。
```

每张图的差异只写在品牌锁之后的场景段、主体段、细节段里。

## 按工位该锁哪几段

| 工位 | 必须锁 | 可以不锁 |
|---|---|---|
| 主图台 | 光位、色温、阴影、背景 | 构图角度、是否模特 |
| 详情页台 | 光位、色温、调色、排版规则 | 每页的场景与信息模块 |
| SKU 台 | 光位、色温、背景、机位 | 颜色、数量、版式 |
| 模特与视频台 | 光位、色温、调色、镜头 | 姿势、场景、服装搭配 |
| 反推台 | 自有产品的保留清单 | 其余全部按对标图拆解 |

## 用法

本项目的做法是**在提示词里锁**，不引入外部状态文件。原因：技能是按目录拷贝安装的，
多一个 `brand.yaml` 就多一个必须随包分发、且用户要记得改的文件。写在提示词里，
一条提示词自带全部锁，复制到哪里都不丢。

如果确需跨任务复用，把上面的 prepend 段存成自己的文本片段，用的时候粘进第一条即可。

## 校验

套图出完后，用 `python tools/visual_audit.py` 做一致性提示（感知哈希 + 颜色直方图）。
它是启发式，分数只用于提示复核，不能作为通过或不通过的最终依据。
