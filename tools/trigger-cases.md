# 触发回归用例集

用途：技能或路由表改版前后，用同一组输入对比触发与路由是否退化。

**自动化跑法**：CI 与本地都跑 `npx promptfoo@0.124.1 eval -c evals/promptfooconfig.yaml`，用例数据源是 `evals/cases.json`。本文件是同一批用例的人类可读视图，两边由 `python evals/check_cases.py` 校验一致，改用例时两处都要改。

**人工核对口径**：在装了本库技能的会话里逐条贴入，核对首轮响应是否命中「预期」。带图片的用例用任一产品图替代；路由结论以回答开头的技能名与文档路径为准。

| # | 输入 | 预期路由 |

## 判读说明

- 用例 17、18 是分流主判据：首轮响应应出现「转用/转交 ecom-main-image-prompts（或 detail-page）」的动作或直接按该导演流程执行。
- 用例 19 检验 02/07 裁决规则是否稳定；用例 20 检验「白底」仍按裸主图判据转交（现行判据的排除列表不含白底）。
- 用例 23 用点名篇号的方式覆盖 02 号通用白底主图 SOP，与用例 20 互补：不点名时转交导演，点名篇号时走库内 SOP。
- 若某用例连续两次冒烟结果与预期不符，先检查对应 SKILL.md 的 description 与路由判据，再决定是否调整。
- 文本质量抽检已单独建在 `evals/quality-cases.json`（按 SOP 硬规则评分），图片输出仍人工看。
