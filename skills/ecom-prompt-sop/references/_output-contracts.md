# 输出契约

> 本文件规定五个工位各自交付物**必须包含哪些段**。SKILL.md 说「产出什么」，这里说「交出来长什么样」。
> 交付前逐条核对：缺段就是未完成，不是「简化版」。

## 为什么要有它

同样的「一套主图提示词」，有无规划表、有无合规检查、有无保留清单，可执行性差一个量级。模板给的是内容，契约给的是结构——两者都到位，产物才能被下游直接接手（设计师照着做、机检照着验、下次照着改）。

契约只管结构，不管内容风格。

## 通用要求（所有工位）

| 项 | 要求 |
|---|---|
| 占位符 | 原子里的 `placeholders` 必须全部替换，产物里不得残留 `【】`、`{{}}`、`[]` |
| 规则自查 | 该原子 `rules` 逐条过一遍，冲突处写明取舍理由 |
| 边界句 | 每条提示词末尾以输出边界句收尾（禁止项、不得继承项） |
| 不确定性 | 推断的信息标注「假设」，不得写成已确认事实 |

## ① AI 主图台

交付物 = **主图规划表** + **逐张提示词** + **合规检查**。

规划表每张一行，必须含这 7 列：

| 列 | 内容 |
|---|---|
| 序号 | 第几张 |
| 职责 | 首图/卖点/场景/细节/规格/收口等，一张只担一个职责 |
| 比例与尺寸 | 目标平台要求的具体值 |
| 背景 | 纯白/浅色/场景，写清具体环境 |
| 是否模特 | 有/无；有则写清露脸规则 |
| 文字规则 | 图内文字有无、内容、渲染方式 |
| 核心信息 | 这张要传达的唯一主张 |

逐张提示词必须含这 5 段：

1. **保留清单** — 产品外观、结构、配色、Logo 位置，逐张完整复用（不得写「同上」）
2. **画面描述** — 主体、构图、材质、光位、镜头
3. **文字层** — 图内文字或明确「无文字」
4. **平台约束** — 该平台的硬性要求（白底、占比、比例、尺寸）
5. **输出边界句** — 禁止出现什么

合规检查必须覆盖：首图规范是否核对、卖点是否有依据、保留清单是否逐张复用、AI 标注义务是否履行。

## ② AI 详情页台

交付物 = **页面规划** + **逐页提示词**。

页面规划每页一行，必须含这 6 列：

| 列 | 内容 |
|---|---|
| 屏序 | 第几屏 |
| 页面主题 | 这一屏只讲一件事 |
| 买家疑问 | 这一屏回答哪个具体问题 |
| 信息块 | 必含的信息单元 |
| 视觉手法 | 构图/对比/特写/拆解等 |
| 与相邻屏的区别 | 说明为什么不重复 |

逐页提示词必须含这 4 段：

1. **锁定段** — 产品外观锁定，逐页完整重写
2. **信息层** — 该页要传的具体信息，带证据
3. **视觉层** — 版式、层级、色彩、留白
4. **边界句** — 禁止项

合规检查必须覆盖：页面主题是否互不重复、防模板化自检是否做过、证据是否可溯源。

## ③ SKU 批量与跨平台台

交付物 = **变体规划** + **逐张提示词** + **规格转换结果**。

变体规划每个变体一行，必须含这 5 列：

| 列 | 内容 |
|---|---|
| 变体归属 | 属于哪个产品/哪组 SKU |
| 改什么 | 只允许：数量、颜色、版式、比例 |
| 不改什么 | 明确列出必须原样保留的部分 |
| 目标规格 | 平台、比例、尺寸 |
| 张数 | 该变体出几张 |

规格转换结果必须写明：源比例 → 目标比例、是否裁切、如何补齐（补边/扩画布/重排）。

## ④ 模特与视频台

**模特图**交付物 = 模特图规划 + 逐张提示词。规划必须含：模特特征锁定（人脸不漂移）、服装款式锁定、姿势、露脸规则、场景。

**视频**交付物 = 分镜表 + 时间轴提示词。分镜表必须含：镜号、时长、画面内容、运镜、转场。时间轴提示词必须按秒标注，不得只写静态画面描述。

## ⑤ 图片反推台

交付物 = **拆解表** + **替换后提示词** + **不继承清单**。

拆解表必须含：原图要素（主体/构图/光位/色彩/文字/场景）、可复用部分、必须替换部分。

不继承清单必须明确列出：品牌名、商品特性、Logo、文案、模特身份——这些一律不得带进新提示词。

## 自检清单（交付前过一遍）

- [ ] 每个占位符都已替换，无 `【】`、`{{}}`、`[]` 残留
- [ ] 规划表/拆解表的列一个不少
- [ ] 每条提示词都有保留清单（或锁定段）与边界句
- [ ] 品与品的区别说清楚了（不重复）
- [ ] 推断信息已标「假设」
- [ ] 该平台的硬性约束已写进提示词，不是只写在说明里
