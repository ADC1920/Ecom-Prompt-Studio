# GPT-Image 系

> 适用：GPT-Image 2 / 2.5 系。快照 2026-11。

## 一句话差异

**分层结构化，文字用引号，`quality` 是独立的保真度杠杆。** 它吃标签化的分段结构，不吃长段散文；写清层次比写得多更重要。

## 分层结构

按这五层成段，每层一段，顺序固定：

```
任务：为【产品】生成一张【用途】图。
主体：【产品外观锁定描述，逐字复用保留清单】。
结构约束：构图、机位、比例、产品占画面比例。
光线与材质：光位、色温、材质表现、接触影。
输出边界：不出现【文字/logo/水印/多余道具/其他禁止项】。
```

层次乱了它也照做，但细节会丢——把该保留的放在「主体」层，别塞进结尾。

## 保真度是独立旋钮

`quality` 不是画质档位，是**保真倾向**。需要产品细节、Logo、包装文字准确时提高它；要快速看构图时压低它再重出。这条比在提示词里反复强调「保持产品不变」有用。

## 多图参考的角色要写明

支持多图输入，但必须说清每张图的角色：

```
图 1 为产品外观基准；图 2 仅用于确认包装印刷细节；图 3 为场景参考，只取其光线氛围，不取其产品。
```

不写角色，它会自行综合，产物既不像图 1 也不像图 3。

## 文字渲染

中文渲染较强，长文本准确率会下降。要点：

1. 文字用引号包裹：`顶部居中写"夏日限定"四个字`。
2. 指定字体气质与字重：`粗黑体，字重偏重`。
3. 指定位置与相对尺寸：`位于画面上方 1/3 居中，字高约占画面宽度 12%`。
4. 超过 20 字的成段文字，一律生成后人工排版。

## 没有负词字段

同样没有 negative prompt。用「输出边界」句集中写禁止项，一句话列全部，不要每段都提一遍。

## 编辑类任务的两栏逻辑

改图时按三栏列清：

```
改动：只把背景换成浅灰无缝。
保留：产品轮廓、颜色、Logo 位置、构图与光位全部不变。
约束：不新增道具，不改变产品比例。
```

## 常见误用

- 写成散文式长段落——它会挑着做，细节容易漏。
- 用 `quality` 当画质档位，指望它把糊图变清晰。
- 多图参考不给角色分工，让它自己综合。
- 在每层都重复一遍「不要文字」，浪费篇幅且互相稀释。
