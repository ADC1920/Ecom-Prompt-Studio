# Qwen-Image 系

> 适用：Qwen-Image 2.1 Pro / 3.0 系。快照 2026-11。

## 一句话差异

**支持千 token 级长指令，完整 SOP 原文可以直接投喂。** 这是它与大多数模型最实际的差别——长约束不会被截断或稀释。

## 该改什么

基本不用改。产品锁定条款、保留清单、边界句可以整段保留，不需要压缩成短句。

只有一处要动：**不要为了「让模型更好理解」而重写 SOP**。重写会稀释原文里精确的产品锁定表述，反而更容易漂移。

## 负词字段分版本

- **2.1 系**：没有 negative prompt 字段，用自然语言边界句。
- **3.0 系**：支持 `negative_prompt`，可以把禁止项集中成列表。

写提示词前先确认目标版本，别把负词列表塞给 2.1。

## 参考图排序

- 2.1 系：支持 1-10 张参考图。
- 3.0 系：支持 1-3 张。

图生图时按「产品主图在前、细节图在后」排序，并在提示词里说明每张图的职责。参考图数量超上限时，删次要角度，别删产品主图。

## 文字渲染

强化汉字渲染，短标题稳定。主标题 ≤10 字更稳；长段落与密集排版仍需生成后人工校对。

## 常见误用

- 把长 SOP 压缩成短提示词——浪费了它最能吃长指令的优势。
- 给 2.1 系写 `negative_prompt` 字段——不生效。
- 参考图超过版本上限还硬塞，导致静默丢弃其中几张。
