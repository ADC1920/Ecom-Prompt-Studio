# 模型写法差异库

> 2026-11 快照。生图工具迭代快（约三到四个月一代），此处只记**写法层面的实际差异**，不追参数表；能力与参数以工具官方文档与实测为准。
>
> 用法：`SKILL.md` 里先读 `tool-adaptation.md` 拿到通用写法，用户点名了具体模型再来这里读对应文件。每个文件只回答一件事——**同一个提示词，换成这个模型该怎么改**。

## 为什么按模型分文件

同一条提示词给不同模型，效果差异不在「词够不够漂亮」，而在语法层：有的模型吃连续自然语言、写焦段光圈会直接降低质量；有的模型要标签化分层、不写结构就丢细节；有的明确支持负词字段，有的只能靠正向句规避。

把这些差异写进一份通用文档，结果是每种模型都写一点、都不够具体，模型按通用规则改写后反而更差。所以拆开，一处只讲一个模型。

## 通用不变项（所有模型都适用，不重复写在各文件里）

1. 主体在前、材质光线居中、文字与边界收尾，一份提示词内保持同一层级顺序。
2. 图内文字用引号包裹，主标题 ≤10 字、副标题 ≤20 字、字体层级 ≤3 级。
3. 不用「8k / masterpiece / hyperrealistic / 极致 / 完美」这类空洞词，改用材质、光位、镜头与物理关系描述。
4. 每条提示词以输出边界句收尾（禁止项、不得继承项）。
5. 具体模型文件只写它与通用写法的差异，不重复上面五条。
