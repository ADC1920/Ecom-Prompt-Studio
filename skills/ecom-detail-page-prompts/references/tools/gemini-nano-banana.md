# Gemini / Nano Banana 系

> 适用：Nano Banana Pro、Nano Banana 2.x 及 Gemini 图像编辑入口。快照 2026-11。

## 一句话差异

**对话式，不谈镜头参数。** 写 `50mm f/1.8`、ISO、光比数字这类摄影机参数会降低质量——这类模型不是按摄影参数建模的，它读的是对画面的自然语言描述。

## 该改什么

| 通用写法 | 改成 |
|---|---|
| `85mm 微距，f/2.8，浅景深` | `近距特写，背景明显虚化` |
| `主光左上 45 度，5500K` | `光从画面左上打来，冷白偏中性` |
| `1/125s 快门` | 删掉，不表达 |
| 长串标签（`product, white bg, studio, soft light`） | 连成句子：`产品立在纯白背景前，顶部柔光，地面有极淡接触影` |

保留可以量化的东西：色值写 `#FFFFFF` 比写「纯白」稳；画面占比写「产品占画面 85%」比写「产品很大」准。

## 多图参考怎么用

这类模型的强项是参考图一致性，十张级输入。用法：

1. 参考图排序：产品主图在前，细节图在后。
2. 提示词里逐张点名职责：`图 1 是产品正面，图 2 是包装细节；以图 1 为准，图 2 只用于确认材质`。
3. 参考图之间不一致时，指定以谁为准，别让模型自己选。

## 分步修图（这是它最该用的姿势）

一次只改一个变量，每步重申保留清单：

```
第 1 步：用完整提示词生成基础图。
第 2 步：保留产品与构图不变，只把背景换成【】。
第 3 步：保留画面全部元素，只把主标题改成"【】"。
```

效果变差时回退上一步重新下指令，不要在坏结果上叠加新要求。

## 没有负词字段

用正向句或「不要」句，不要指望 negative prompt：

- 差：`--no text, --no watermark`
- 好：`画面不出现任何文字、logo 或水印`

## 文字渲染

支持多语言文字，短标题稳定；长段与密集排版仍可能出错。主标题 ≤10 字、副标题 ≤20 字，字号占画面宽度 10% 以上更稳。密集参数表、规格表一律生成后人工补字，不要赌一次成型。

## 常见误用

- 把 SD 时代的关键词堆（`8k, masterpiece, best quality`）搬过来——无效，还会把成片推向塑料感。
- 把整段结构化标签表直接投喂——它更适合连贯句子。
- 一次给五条改动要求——分步改，一步一变量。
