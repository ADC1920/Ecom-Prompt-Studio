# /ecom:detail

按五工位详情页台出逐页方案。

参数（都可选，缺了先问，不要猜）：`$ARGUMENTS`

执行步骤：

1. 用 `query_atom` 定位原子，产物填详情页。
2. 用 `get_template` 取模板、规则与清单。
3. 先出**页面规划**：每页的关键词与职责，相邻页主题不得重复。
4. 再出**逐页提示词**：每页先写产品锁定约束，再写设计画面。
5. 每页写清构图、景别、镜头、产品位置、信息布局、文字排版、背景材质、光影，不得只写「放标题」。
6. 定稿前用 `validate_prompt` 自查。

防模板化自检：整套关键词与信息模块换个产品也能用，就重写。

没有品类线索的裸详情页方案，转 `ecom-detail-page-prompts` 技能。
