# /ecom:main

按五工位主图台出主图方案。

参数（都可选，缺了先问，不要猜）：`$ARGUMENTS`

执行步骤：

1. 用 `query_atom` 工具定位原子，参数取用户的品类、产物（主图）、动作。
2. 读命中原子：`get_template` 取模板与规则。
3. 先出**主图规划表**（每张的职责、比例、背景、是否模特、文字规则、核心），再出**逐张提示词**。
4. 每条提示词定稿前用 `validate_prompt` 自查，带上 platform 与 scenario。
5. 按主图台门禁交付：产品保留清单在每张里完整复用；卖点分级只说已确认与有依据的；首图符合目标平台规范；每张以输出边界句收尾。

没有品类线索的裸主图方案，转 `ecom-main-image-prompts` 技能，不要在本命令内硬出。
