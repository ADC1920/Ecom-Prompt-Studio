# /ecom:sku

按五工位 SKU 台做批量变体、比例转换或图内文字翻译。

参数（都可选，缺了先问，不要猜）：`$ARGUMENTS`

执行步骤：

1. 用 `query_atom` 定位原子，动作填批量或翻译。
2. `get_template` 取模板与规则。
3. 先出**SKU 变体规划**：每个变体归属哪个 SKU、改什么（数量、颜色、版式）、不改什么。
4. 再出逐张提示词。主体只改数量、颜色、版式；转换后主体不裁切；文字只译不改。
5. 定稿前 `validate_prompt` 自查。

比例转换（3:4 转 1:1）必须写明不裁切主体，改用补背景或移位。
