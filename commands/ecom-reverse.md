# /ecom:reverse

按五工位反推台把别人的图或视频拆成自己的提示词。

参数（都可选，缺了先问，不要猜）：`$ARGUMENTS`

执行步骤：

1. 用 `query_atom` 定位原子，动作填反推或翻新。
2. `get_template` 取模板与规则。
3. 先出**拆解表**：画面结构、镜头、光影、信息层级，逐项拆开。
4. 再出**替换后完整提示词**：换成自有产品，品牌名替换，商品特性不继承。
5. 附**不继承清单**：明确哪些是对方的、不跟着抄。
6. 视频反推必出分镜（时间轴镜头），不得只给静态描述。

反推的是别人的素材，不得复制其品牌元素与独占设计。
